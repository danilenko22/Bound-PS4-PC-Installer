### ✨ v1.0.1 – New look

* **Installer banner:** original abstract artwork (no game assets) instead of a plain window.
* **Launcher banner:** shows Bound's title image taken from **your own** installed game files.
* Progress bar only appears while installing.

Everything from v1.0.0 is unchanged: the 60 FPS fix (`readbacks_mode = 1`), no PSN error at startup, PKG or folder install, launcher options and English/Spanish interface.

**Already installed v1.0.0?** Run the new `Bound.exe` and install over the same folder — your saves are kept.
